SIMULADOR DEL SISTEMA DE LORENZ

Caos determinista y efecto mariposa

1. Descripción del fenómeno

El Sistema de Lorenz es un modelo matemático de tres ecuaciones diferenciales no lineales. Permite estudiar el comportamiento caótico y la sensibilidad a pequeñas variaciones en las condiciones iniciales.

2. Modelo matemático

dx/dt = σ(y - x)

dy/dt = x(ρ - z) - y

dz/dt = xy - βz

Los parámetros y variables corresponden al modelo normalizado de Lorenz.

7. Interpretación

Al modificar los parámetros o las condiciones iniciales, cambia la evolución de las trayectorias. Con los parámetros clásicos, el sistema puede presentar el atractor de Lorenz. La comparación permite observar la sensibilidad a condiciones iniciales cercanas.
